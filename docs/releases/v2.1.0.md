## cmddeck

Browse, search, and launch installed commands from a fast terminal interface.
One standalone Go binary, with no runtime dependencies.

- Explore commands by purpose, with descriptions and similar commands.
- Press **Enter** to run a selected command immediately.
- Press **Ctrl+E** to edit optional arguments with quoting and inline validation.
- Press **Tab** for details, or **Ctrl+R** after execution to run again.
- Browse a refreshed layout with search, highlighted selection, and a preview panel.
- Basic Unix commands are hidden by default; use `--all` to include them.

### Linux downloads

Choose `linux_amd64` for x86-64 PCs or `linux_arm64` for ARM64 machines.
Extract the archive and install the single executable:

```sh
install -Dm755 cmddeck "$HOME/.local/bin/cmddeck"
cmddeck
```

`SHA256SUMS` contains checksums for both archives.
